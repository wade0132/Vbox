# 微影

**基于 AVBox 二次开发的开源 Android 影视播放器框架**

版本 `1.6.0` · 包名 `com.github.vying.osc` · Android 7.0+（`arm64-v8a`）· [AGPL-3.0](LICENSE)

[下载安装包](https://github.com/wade0132/weiying/releases) · [提交 Issue](https://github.com/wade0132/weiying/issues) · [上游项目 AVBox](https://github.com/XiaochangXu/AVBox)
</div>

> 本软件仅提供播放界面、源配置管理与本地播放能力，默认**不预置、不内置、不提供**任何影视内容、直播频道、节目单或第三方解析接口。使用前请阅读文末的[免责声明与用户协议](#免责声明与用户协议)。

## 项目简介

微影 是在 [AVBox](https://github.com/XiaochangXu/AVBox) v1.4.0 基础上二次开发的 Android 播放器框架，保留上游的点播、直播、TMDB 刮削与播放能力，并新增坚果云 WebDAV 多端同步与若干界面改进。

- 版本：versionName `1.6.0` / versionCode `47`
- 包名：`com.github.vying.osc`
- 架构：`arm64-v8a`，Android 7.0+
- 体积：启用 R8 压缩并以官方 1.4.0 底包重组后，安装包约 29.25 MB
- 签名：沿用官方 release 证书（纯 v2 签名）
- 源码：本仓库 `main` 分支即为二次开发后的完整可编译工程

> **升级提示**：应用名与包名已由「V影视 / `com.github.VVbox.osc`」更改为「微影 / `com.github.vying.osc`」。包名变更意味着无法覆盖安装旧版本，请先卸载旧版再安装；观影记录可通过坚果云同步备份/恢复。

## 主要功能

### 坚果云多端同步

通过坚果云 WebDAV（**第三方应用密码**，非登录密码）在多台设备之间同步数据。合并按 `recordAt` / `progressAt` 字段级时间戳进行，墓碑保留 90 天。

| 同步内容 | 说明 |
| --- | --- |
| 观影历史 | 按 `sourceKey\|vodId` 合并，计数与「历史」页同源 |
| 分集播放进度 | 同步真实毫秒进度并写回播放器进度缓存，多端续播 |
| App 设置 / 点播 / 直播 / TMDB 配置 | 云端备份、一键恢复、一键清除 |

**自动同步逻辑**覆盖冷启动、从后台回到前台、定时轮询、网络恢复补做、刚开启同步等全部触发源；等待订阅 CID 就绪，重复触发串行合并，失败按约 3s / 12s / 40s 指数退避重试 3 次，401/403 等不可重试错误立即结束，无网络时标记待补。同步界面会显示操作结果提示与上次自动同步状态。

配置路径：**设置 → 坚果云观影记录同步**，填写坚果云账号与第三方应用密码，开启「打开 APP 自动同步」。多端使用同一坚果云账号与同一配置目录即可互相同步；配置恢复后建议重启 App。

### 其他改进

- 移除上游 1.3.0 起已废弃的 M3U8 净化功能（开关、文案、KV 键、播放分支与底层实现类全部清除）
- 修复 UI 错位与网络 401 报错
- 设置页 GitHub 仓库链接改为本项目，关于页免责声明改写为「基于 axbox 二开」并补充出处链接
- 开启 R8 代码与资源压缩，并以官方 1.4.0 底包重组，安装包约 29.25 MB
- 修复全屏播放时亮度/音量分区随机型横竖屏配置偏移的问题（小米 13 等手机横屏下左侧亮度区缩水）
- 首页新增「最近观看」卡片：位于「全部分类」上方，横向滑动展示最新 15 条播放记录，UI 与交互沿用「热门电影」卡片；右上角「全部」直达「记录 → 历史」；剧名下方显示播放进度（播放到第几集 + 当前集已看百分比，数据复用历史记录）
- 「最近观看」卡片点击后直接全屏播放对应剧集并续播（跳过详情页浏览）；进度与集数沿用「记录 → 历史」的播放记录，其它板块点击行为不变
- 首页「海报样式」切换为「普通」后同样显示「最近观看」：位于「订阅源」下方，分类标签与影片网格整体退位下沉；两种布局共用同一板块，UI、进度、点击与「全部」跳转完全一致。平板横屏下自动收窄卡片并跟随侧栏偏移，避免挤压网格可视区

## 下载与安装

前往 [Releases 页面](https://github.com/wade0132/weiying/releases) 下载最新安装包（`arm64-v8a`，Android 7.0+）。Release 资产统一使用英文文件名（GitHub 不支持中文资产名），内容与本地同名文件逐字节一致。

> 由于包名已变更，从旧版「V影视」升级时请先卸载旧应用；观影记录可通过坚果云同步备份与恢复。

## 从源码构建

- JDK 21、Gradle 9.9.1、Android SDK（compileSdk 35+、build-tools 36）、NDK 27.2
- Python 3.10（Chaquopy 构建需要）
- `./gradlew assembleDebug`

同步模块可独立接入上游 AVBox，接入步骤见 `avbox-nutstore-sync.zip` 内的 `INTEGRATION.md`。
